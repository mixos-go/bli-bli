# Joined Discount List V1

### Overview

API Version

GETCopy

Requirement

Requires a valid Blibli SKU on the path parameter.

Expectation

This API is to check the joined promos if there is an SKU got rejected when it was registered into a promo.

Validation

1. This API can only be accessed by active Seller.
2. If the product has only one pickup point, then the pickup point code in the parameter field will not be mandatory.
3. If the product has more than one pickup point, then you must send the pickup point code. Otherwise, the response will return an error.

Limitation

50 requests per minute per store code.

API raw string
GET\n\n\nTue May 12 16:28:52 WIB 2020\n/seller/v1/promos/products/TOQ-15130-00001-00001/promos/discounts
