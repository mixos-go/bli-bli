# Update Product Stock by Exact Value V1

### Overview

API Version

PUTCopy

Requirement

1. Require `blibliSku` on path
2. Set the expected exact value on `availableStock`
3. The product is neither archived nor in suspended state

Expectation

1. Synchronous API. This API is not intended to handle high throughput. Not compatible to perform bulk data request.
2. Able to update archived product.
3. Able to update `availableStock` using the exact value that expected to be applied.
4. If the current stock is 6, then you expect the available stock is 10, then you should set the value as 10.

Validation

If the product has more than one Pickup Point assigned, then you must select one pickup point code and input it in the field request parameter. Otherwise, the system will return an error.

Limitation

1. Limited to 60 requests per minute per store
2. Set your API hit rate wisely, in future development this API will have a limit per minute to avoid abusive requests.
