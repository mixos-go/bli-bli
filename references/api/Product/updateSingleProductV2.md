# Update Single Product V2

### Overview

API Version

PUTCopy

Previously, this API was named as PUT Update Product by Blibli SKU V2.

Requirement

1. Require `blibliSku` on path
2. `price` field is required to be assigned on request body
3. The product is neither archived nor in suspended state

Expectation

1. Synchronous API. This API is not intended to handle high throughput. Not compatible to perform bulk data request.
2. Able to update `sellerSku`, `buyable`, and `price`.
3. Able to update the CNC Flag
4. The value of displayable will always follow the value of buyable . The product will be displayed (displayable: true) if the value of buyable is also true. Vice versa.

Validation

- If the product is included on Blibli Promo (Campaign) or Flash Sale and the campaign status is REGISTERED or REVIEW_SKU, then Seller can only update the Product Price as long as the price changes following min-max allowed price range.
- In order to update the CNC Flag of the product to be true , the store and the assigned pickup point should have the CNC feature activated, otherwise the system will return an error. If you want to set your store to be CNC store, please contact the seller.care@blibli.com.
- If you did not send the request without pickup point code: If the product item have 1 pickup point, then the system will continue the update process. If the product item have more than 1 pickup point (multi pickup point), then the system will return an error. To avoid the error, user should send the pickup point code too.

Campaign (REGULAR)/Flash Sale Price Update Validation

Blibli Promo has 2 types of promo. It could be Campaign (REGULAR) or Flash Sale. Below are the validation when updating the Blibli Promo price based on Promo timeline:

1. Product Registration During Product registration period, there is a difference when registering the product to the promo: Campaign (REGULAR): When the updated price is out of the current promo price range, then the update succeed but the system will return a warning message. This action will make the product`s excluded from campaign (REGULAR) and in order to re-join the Campaign the product`s price need to be revised according to the campaign (REGULAR) price range. Flash Sale: When the updated price is out of the current promo price range, then the update will be failed.
2. Product Review When the product is on review for Campaign (REGULAR)/Flash Sale that has not started yet. The price can only be updated within the eligible promo price range.
3. Campaign (REGULAR)/Flash Sale is Live No price update is allowed when the product Campaign (REGULAR)/Flash Sale review has been finished and either it`s waiting the promo to be started or currently going.

The eligible promo price range can be find by using the GET Blibli Promo Detail V1 API .

Limitation

1. Limited to 5 requests per hour per Blibli SKU
2. Set your API hit rate wisely, in future development this API will have a limit per minute to avoid abusive requests.
