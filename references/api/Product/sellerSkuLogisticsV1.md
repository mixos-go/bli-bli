# Seller SKU Logistics V1

### Overview

API Version

GETCopy

Requirement

1. Requires blibliSku on the path parameter.
2. This API is only for live product.

Expectation

1. List of logistic services that can be assigned by a Seller to the specific blibliSku that is inputted in the path parameter.
2. This API will help User to configure the product using Update Bulk Product V1 API.
3. If User get logistic list for non-regular product (BP or BOPIS), it will always shows an empty content (empty array or [])
4. If the geolocation value is true , it means when Sellers want to assign this logistic service, Sellers should make sure that they have already set up the geolocation information to the specific blibliSku.
5. If the geolocation value is false , it means when Sellers want to assign this logistic service, they do not need to set the geolocation info on the pickup point of that product.

Validation

Should use the correct value of blibliSku on the path parameter. The error will be appeared if User input the invalid blibliSku or blibliSku value of other store.

Limitation

15 requests per 10 minutes per Blibli SKU

API raw string
GET\n\n\nTue May 12 16:28:52 WIB 2020\n/seller/v1/products/TOQ-15131-00564-00001/logistics
