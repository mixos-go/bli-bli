# Update Product by blibliSku V1

### Overview

API Version

PATCHCopy

This API is deprecated, so it will no longer supported. Please use **Update Single Product V2** instead.

Requirement

1. `sale` value should not be more than `regular` value
2. `regular` and `sale` value should not be less than 1000

Expectation

1. Following are the allowed fields to be updated
2. Users are allowed to update only one field, or all those three at a time.

Validation

1. The product is neither archived nor in suspended state
2. If the product is included on Blibli Promo (Campaign) or Flash Sale and the campaign status is REGISTERED or REVIEW_SKU, then Seller can only update the Product Price as long as the price changes following min-max allowed price range.

Limitation

Limited to 1 request per 10 minutes per store.
