# Product List V1

### Overview

API Version

GETCopy

This is a deprecated API, currently we are not supporting this API anymore. Please use the **POST Product List V3** instead.

This API will return active product per item or variant from Blibli Seller Center . When your product still in process, it will not be shown here.
