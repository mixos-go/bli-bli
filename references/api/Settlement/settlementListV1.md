# Settlement List V1

### Overview

API Version

POSTCopy

Expectation

This finance settlement always available at the end of period and after the settlement process has been finished in Blibli`s system. There are two types of settlement period:

- Daily: This finance settlement will be available in every working day (Mon-Fri). This only applied for Indonesian seller
- Biweekly: This one will be available in every two weeks of working days. Only applied for International seller

![image](https://www.static-src.com/siva/asset/05_2025/Settlement_Timeline.png)

1. Settlement list is the list that contains every settlement that related to your sales profit, and also includes the adjustment that might occurred. The settlement adjusment include the unpaid settlement which caused by the carried over settlement or the settlement that on hold.
2. The Carry Over settlement is occurred when the amount is less than 10.000 IDR. The settlement will be paid once the amount is reached more than 10.000 IDR. If the value of carryOver is True, it means the settlement contains the value of carry over amount and has been calculated with the current settlement. The specific amount of carryOver can be obtained using GET Settlement Detail - Adjustments.
3. The On hold settlement will be generated by system as information, and will be paid until the on hold value become False .
4. This is the sample when using the filter date (the value that will be sent on request body must use millisecond number format): Payment Start Date: January 1, 2020 Payment End Date: November 1, 2020 Period Start Date: May 1, 2020 Period End Date: June 1, 2020 The response will give you settlement that contains all the purchases with all the existed status that occurred in May to June that has been paid within January to November 2020.

Limitation

50 requests per hour per store code.

API raw string
GET\n\n\nTue May 12 16:28:52 WIB 2020\n/seller/v1/settlements/filter
