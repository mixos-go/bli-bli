# Remove Product Voucher V1

### Overview

API Version

DELETECopy

Requirement

1. Requires a valid voucher code on the path parameter.
2. Requires a valid Blibli SKU on the path parameter. The Blibli SKU should be the one that is registered to a voucher.

Expectation

- Remove the registered product of the specified voucher.
- Able to remove seller voucher from the product which have multi pickup point.

Validation

1. This API can only be accessed by active Seller.
2. This feature only enabled for voucher with status ACTIVE or PENDING. Only for the voucher that applied to specific Blibli SKU.
3. The product will be only removed if there are more than one product registered on the specified voucher.
4. Cannot remove the last one product of the specified voucher.
5. Cannot remove the product under a voucher with apply to all product.
6. If you did not send the request without pickup point code: If the product item have 1 pickup point, then the system will continue the update process. If the product item have more than 1 pickup point (multi pickup point), then the system will return an error. To avoid the error, user should send the pickup point code too.

Limitation

5 requests per minute per Blibli SKU.
