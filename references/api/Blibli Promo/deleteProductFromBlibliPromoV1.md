# Delete Product from Blibli Promo V1

### Overview

API Version

DELETECopy

Requirement

1. Requires Promo Code with status REGISTERED on the path parameter.
2. In order to get the Promo Code, User is required to hit the GET Product List of Blibli Promo V1 API.
3. Requires Blibli SKU on the path parameter.

Expectation

This API will delete a registered product from the specified Blibli Promo.

Validation

- This API can only be accessed by active Seller.
- If the product has only one pickup point, then the pickup point code will not be mandatory.
- If the product has more than one pickup point, then you must send the pickup point code. Otherwise, the process will fail.

Limitation

5 requests per Blibli SKU per hour.
