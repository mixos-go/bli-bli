# Blibli Promo List V1

### Overview

API Version

POSTCopy

Expectation

- Give you a list of available Blibli Promo that can be filtered and sorted by several fields.
- Expect faster response by sending the countSellerProducts with the value `false`

Validation

This API can only be accessed by active Seller.

Limitation

- 5 requests per Store Code per hour.
- Maximum limit for paging size is 30.
